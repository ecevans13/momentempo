    1. **Create `backend/app/config.py`** — pydantic-settings configuration:
       ```python
       from functools import lru_cache
       from pydantic_settings import BaseSettings, SettingsConfigDict

       class Settings(BaseSettings):
           strava_client_id: int
           strava_client_secret: str
           strava_redirect_uri: str = "http://localhost:8000/auth/callback"
           database_url: str = "sqlite:///backend/data/stravviz.db"

           model_config = SettingsConfigDict(
               env_file=".env",
               env_file_encoding="utf-8",
           )

       @lru_cache
       def get_settings() -> Settings:
           return Settings()
       ```
       **Note on `env_file` path:** The `.env` file is at the project root. Since the server will be started from the project root (e.g., `uvicorn backend.app.main:app`), the relative path `.env` is correct. Do NOT use an absolute path.

    2. **Create `backend/app/models.py`** — Token SQLModel table:
       ```python
       from sqlmodel import Field, SQLModel

       class Token(SQLModel, table=True):
           id: int | None = Field(default=None, primary_key=True)
           access_token: str
           refresh_token: str
           expires_at: int           # Unix epoch timestamp from Strava
           token_type: str = "Bearer"
           scope: str = ""
           athlete_id: int | None = None
           athlete_name: str | None = None
           athlete_avatar_url: str | None = None
       ```
       This is a singleton table (only one row, id=1). The athlete fields are populated from the OAuth response to display on the success page and for later use.

    3. **Create `backend/app/database.py`** — SQLModel engine and session:
       ```python
       from sqlmodel import SQLModel, Session, create_engine
       from backend.app.config import get_settings

       def get_engine():
           settings = get_settings()
           return create_engine(
               settings.database_url,
               connect_args={"check_same_thread": False},  # MANDATORY for FastAPI + SQLite
           )

       def create_db_and_tables(engine):
           SQLModel.metadata.create_all(engine)

       def get_session(engine):
           with Session(engine) as session:
               yield session
       ```
       **Critical:** Always include `check_same_thread=False` — without it, SQLite throws threading errors under FastAPI's thread pool.

       The engine should be created once and stored on `app.state` during lifespan, then `get_session` should be a dependency that uses `app.state.engine`. This avoids module-level engine creation that breaks tests.

    4. **Create `backend/app/main.py`** — FastAPI application:

         - Create the SQLModel engine and store on `app.state.engine`

         - Format: `"%(asctime)s %(levelname)s %(name)s: %(message)s"`
         - Level: INFO

       **Import structure:** Use relative imports within the backend.app package (e.g., `from .database import ...`) OR use the full path (`from backend.app.database import ...`). Be consistent. Relative imports are preferred within the package.
