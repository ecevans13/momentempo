    1. **Create `backend/app/services/strava_auth.py`** — Core auth logic:

       **Constants:**
       ```python
       STRAVA_AUTH_URL = "https://www.strava.com/oauth/authorize"
       STRAVA_TOKEN_URL = "https://www.strava.com/api/v3/oauth/token"
       REQUIRED_SCOPES = {"activity:read_all"}
       REFRESH_BUFFER_SECONDS = 3600  # Refresh when within 1 hour of expiry
       ```

       **Functions to implement:**

       a) `build_auth_url(settings: Settings) -> str` — Build the Strava OAuth consent URL with:
          - `client_id` from settings
          - `redirect_uri` from settings
          - `response_type=code`
          - `approval_prompt=auto`
          - `scope=activity:read_all,profile:read_all`
          - Use `urllib.parse.urlencode` for proper encoding

       b) `token_needs_refresh(expires_at: int) -> bool` — Returns True if `time.time() >= (expires_at - REFRESH_BUFFER_SECONDS)`

       c) `async exchange_code_for_tokens(code: str, settings: Settings) -> dict` — POST to STRAVA_TOKEN_URL with `grant_type=authorization_code`. Use `httpx.AsyncClient`. Call `response.raise_for_status()`. Return `response.json()`.

       d) `async refresh_access_token(refresh_token: str, settings: Settings) -> dict` — POST to STRAVA_TOKEN_URL with `grant_type=refresh_token`. Use `httpx.AsyncClient`. Call `response.raise_for_status()`. Return `response.json()`.
          **Critical:** The response contains a NEW refresh_token that MUST be persisted. The old one becomes invalid after ~1 hour.

       e) `async ensure_valid_token(session: Session, settings: Settings) -> Token | None` — Core refresh logic:
          - Query for the singleton Token (id=1) from the session
          - If no token exists, return None
          - If token exists and `token_needs_refresh(token.expires_at)` is True:
            - Try to refresh using `refresh_access_token`
            - On success: update token.access_token, token.refresh_token, token.expires_at in the DB, commit, return updated token
            - On failure (httpx.HTTPError, any exception): log the error at WARNING level, do NOT crash, return the existing token (it may still work, or caller handles 401)
          - If token exists and is valid, return it

       f) `async bootstrap_auth(engine, settings: Settings) -> None` — Called during lifespan startup:
          - Open a session using the engine
          - Query for existing token
          - If no token exists: open browser to `build_auth_url(settings)` using `webbrowser.open()`. Log "No stored tokens found — opening browser for Strava authorization" at INFO level. Add a small `await asyncio.sleep(1.0)` BEFORE opening the browser to give the server time to finish binding to the port (prevents "connection refused" on callback).
          - If token exists and needs refresh: call `ensure_valid_token` to refresh silently. Log "Refreshing expired token" at INFO level.
          - If token exists and is valid: do nothing (completely silent per user decision — no log messages about existing valid tokens)

       **Error handling:** All httpx calls should be wrapped in try/except. Network errors during refresh should be logged but NOT raise — the app must continue running (graceful degradation per user decision).

    2. **Create `backend/app/routers/auth.py`** — OAuth routes:

       **Router:** `APIRouter(prefix="/auth", tags=["auth"])`

       a) `GET /auth/login` — Redirects to Strava OAuth consent page:
          - Build auth URL using `build_auth_url(settings)`
          - Return `RedirectResponse(url=auth_url)`
          - This is the manual entry point if the user needs to re-authenticate

       b) `GET /auth/callback` — Handles OAuth redirect from Strava:
          - Parameters: `code: str | None = None`, `error: str | None = None`, `scope: str | None = None`
          - **If error or no code:** Return `HTMLResponse` with an error page (status 400). The error page must:
            - Have a styled HTML page (dark background `#1a1a2e`, white text, centered content)
            - Show the error message (or "Authorization was denied" if no specific error)
            - Include a "Try Again" link that navigates to `/auth/login`
            - Look polished, not plain text

          - **Scope verification:** Parse the `scope` parameter (comma-separated). Check that `activity:read_all` is in the granted scopes. If not, return an HTMLResponse explaining which scopes are needed and a "Connect Again" link to `/auth/login` (status 403).

          - **Token exchange:** Call `exchange_code_for_tokens(code, settings)`. On failure, return error page with the exception message.

          - **Persist token:** Upsert pattern on the Token model (singleton, id=1):
            - Query for existing token with id=1
            - If exists: update access_token, refresh_token, expires_at, scope, athlete fields
            - If not exists: create new Token with id=1
            - Extract athlete info from response: `athlete.id`, `athlete.firstname + " " + athlete.lastname` (stripped), `athlete.profile` (avatar URL)
            - Commit the session

          - **Success page:** Return `HTMLResponse` with a polished success page:
            - Dark themed (background `#1a1a2e`, cards with `#16213e`)
            - Centered card layout
            - Show athlete's avatar image (circular, with CSS `border-radius: 50%`) — use the `profile` URL from the athlete data. If no avatar, show a placeholder circle with initials.
            - Show "Connected as {athlete_name}" as a heading
            - Show "StravaViz is now connected to your Strava account" as subtext
            - Show a subtle "You can close this tab" message
            - Use inline CSS (no external stylesheets needed for this single page)

          - **Wrap the entire exchange in try/except httpx.HTTPError** and return an error page on failure

       **Session dependency:** The auth routes need a database session. Since `get_session` needs the engine from `app.state`, create a dependency that gets it from the request:
       ```python
       from fastapi import Request

       def get_db_session(request: Request):
           engine = request.app.state.engine
           with Session(engine) as session:
               yield session
       ```
       Use `session: Session = Depends(get_db_session)` in route parameters.

       **HTML rendering:** Use simple f-strings or template strings for the HTML pages. Do NOT add Jinja2 as a dependency — these are two simple pages. Define helper functions `render_success_page(athlete: dict) -> str` and `render_error_page(error_message: str) -> str` that return HTML strings.

    3. **Update `backend/app/main.py`** — Wire auth into the app:
       - Import and include the auth router: `app.include_router(auth.router)`
       - Update the lifespan to call `bootstrap_auth(app.state.engine, get_settings())` after database initialization
       - The bootstrap_auth call should be wrapped in try/except to handle startup failures gracefully (log error, continue — the user can manually visit /auth/login)

    **Strava OAuth flow summary (for reference):**
    ```
    1. App starts → bootstrap_auth checks DB → no token → opens browser to Strava consent
    2. User authorizes → Strava redirects to /auth/callback?code=XXX&scope=activity:read_all,...
    3. Callback exchanges code for tokens via POST to Strava
    4. Tokens + athlete info stored in SQLite
    5. Success page shown with athlete name/avatar
    6. Next app start → bootstrap_auth finds valid token → silence
    7. Token near expiry → ensure_valid_token refreshes silently
    ```
