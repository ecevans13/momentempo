```python
class ActivityStream(SQLModel, table=True):
    """Cached GPS stream data for an activity. Null columns = stream not available."""
    activity_id: int = Field(primary_key=True)  # Strava activity ID — not auto-increment

    # Stream arrays — null means the stream was not available for this activity
    latlng: list[Any] | None = Field(default=None, sa_column=Column(JSON, nullable=True))
    altitude: list[float] | None = Field(default=None, sa_column=Column(JSON, nullable=True))
    heartrate: list[int] | None = Field(default=None, sa_column=Column(JSON, nullable=True))
    velocity_smooth: list[float] | None = Field(default=None, sa_column=Column(JSON, nullable=True))
    time: list[int] | None = Field(default=None, sa_column=Column(JSON, nullable=True))
    distance: list[float] | None = Field(default=None, sa_column=Column(JSON, nullable=True))

    # Sentinel: if non-null, streams were fetched (even if no GPS data exists)
    fetched_at: float | None = Field(default=None)
```

Key design points:
- `activity_id` is primary key (not auto-increment) — enables `session.merge()` upsert, same pattern as `Activity`
- All stream columns use `sa_column=Column(JSON, nullable=True)` — explicit nullable avoids SQLModel/SQLAlchemy quirks (see research Pitfall 3)
- `fetched_at` is the sentinel: non-null means "already attempted fetch" regardless of whether GPS data exists

Create `backend/app/services/streams_service.py` with the lazy-fetch-and-cache service function.

The service must implement:

1. **`_extract_stream_data(data: dict, key: str) -> list | None`** — Helper to safely extract a stream's data array from Strava's `key_by_type=true` response. Uses `data.get(key, {}).get("data")` to handle missing streams gracefully (Strava omits unavailable types, does NOT null them — see research Pitfall 2).

2. **`async def fetch_and_cache_streams(activity_id: int, session: Session, settings: Settings) -> ActivityStream | None`** — Main function:
   - **Cache hit check:** `session.get(ActivityStream, activity_id)` — if row exists and `fetched_at is not None`, return it immediately (no API call)
   - **Auth:** Call `ensure_valid_token(session, settings)` — raise `HTTPException(401)` if None
   - **Strava call:** Use `strava_get()` with path `/activities/{activity_id}/streams`, params `{"keys": "latlng,altitude,heartrate,velocity_smooth,time,distance", "key_by_type": "true"}`
   - **404 handling:** If response is 404, store sentinel row (all nulls + fetched_at set) and return it
   - **Parse response:** Extract each stream type via `_extract_stream_data()`
   - **Store:** Create `ActivityStream` with all fields + `fetched_at=time.time()`, use `session.merge()` for idempotent upsert, then `session.commit()`
   - **Return:** The merged instance after `session.refresh()`
