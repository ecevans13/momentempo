```python
@router.get("/{activity_id}/streams")
async def get_activity_streams(request: Request, activity_id: int):
    """Return cached GPS streams for an activity.

    On first call: fetches from Strava and caches. Subsequent calls: reads from cache.
    Activities without GPS return null stream fields (no error).
    """
    with _get_session(request) as session:
        streams = await fetch_and_cache_streams(
            activity_id, session, get_settings()
        )

    if streams is None:
        # Should not happen (fetch_and_cache_streams always returns a row or raises)
        # but handle defensively
        return {
            "activity_id": activity_id,
            "has_gps": False,
            "has_altitude": False,
            "has_heartrate": False,
            "latlng": None,
            "altitude": None,
            "heartrate": None,
            "velocity_smooth": None,
            "time": None,
            "distance": None,
        }

    return {
        "activity_id": activity_id,
        "has_gps": streams.latlng is not None,
        "has_altitude": streams.altitude is not None,
        "has_heartrate": streams.heartrate is not None,
        "latlng": streams.latlng,
        "altitude": streams.altitude,
        "heartrate": streams.heartrate,
        "velocity_smooth": streams.velocity_smooth,
        "time": streams.time,
        "distance": streams.distance,
    }
```

Key design points:
- No new router registration needed — this adds to the existing `/api/activity` router
- Response includes boolean flags (`has_gps`, `has_altitude`, `has_heartrate`) so the frontend can conditionally render map/charts without inspecting arrays
- The `with` session context ensures cleanup even on error
- The endpoint is async because `fetch_and_cache_streams` is async
